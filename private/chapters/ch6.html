01 · Ordered List

Show information in a specific sequence

<ol> <li>Open VS Code</li> <li>Write HTML</li> <li>Save the file</li> </ol>
OL = Ordered List   ·   LI = List Item

<ol> + <li>

Use <ol> when the order or sequence matters.

Each individual entry goes inside <li>.

Common use: steps, rankings, instructions and ordered procedures.
→
steps.html

How to Create a Webpage

  1. Open VS Code
  2. Write HTML
  3. Save the file
The browser automatically displays 1, 2, 3... for a normal ordered list.
Simple meaning: An Ordered List displays items in a sequence. The browser normally gives each item a number. Use <ol> for the list and <li> for each item.

02 · Ordered List Options

Numbers are not the only marker style

<!-- Letters --> <ol type="A"> <li>HTML</li> <li>CSS</li> </ol> <!-- Roman numerals --> <ol type="I">...</ol> <!-- Start / reverse --> <ol start="5">...</ol> <ol reversed>...</ol>
type changes markers · start changes the first value · reversed counts downward

Useful values

type="1"
1, 2, 3
type="A"
A, B, C
type="a"
a, b, c
type="I"
I, II, III
type="i"
i, ii, iii
start="5"
5, 6, 7

reversed changes the direction: 3, 2, 1.

→
ordered.html
A — Letter list
A. HTML    B. CSS    C. JavaScript
I — Roman list
I. HTML    II. CSS    III. JavaScript
start="5"
5. HTML    6. CSS    7. JavaScript
reversed
3. Third    2. Second    1. First
More than 1, 2, 3: type can use numbers, letters or Roman numerals. start changes the starting value, and reversed makes the list count down. These are HTML list features; detailed visual styling can be handled with CSS.

03 · Unordered List

Group items when their order does not matter

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>
UL = Unordered List   ·   LI = List Item

<ul> + <li>

Use <ul> when the order of items is not important.

The browser normally displays a bullet before each item.

Common use: features, skills, navigation choices and ingredients.
→
skills.html

Web Skills

  • HTML
  • CSS
  • JavaScript
The list is grouped visually, but no sequence is required.
Simple meaning: An Unordered List is for a collection of items where sequence is not important. Use <ul> around the list and <li> around each item.

04 · Description List

Connect a term with its explanation

<dl> <dt>HTML</dt> <dd>Structure of a webpage</dd> <dt>CSS</dt> <dd>Style of a webpage</dd> </dl>
DL = Description List · DT = Description Term · DD = Description Details

<dl> structure

<dt> identifies the term.

<dd> gives information or a description about that term.

Useful for: glossaries, definitions, FAQs and name–value information.
→
glossary.html

Web Glossary

HTML
Structure of a webpage
CSS
Style of a webpage
JavaScript
Behaviour and interaction
Simple meaning: A Description List pairs a term with its details. <dl> contains the list, <dt> represents the term, and <dd> represents its description or details.

05 · Nested Lists

Build levels inside a list

<ul> <li>Frontend <ul> <li>HTML</li> <li>CSS</li> </ul> </li> <li>Backend</li> </ul>
Nested = one list placed inside another list item.

Parent → Child

The outer item becomes the parent.

A second list inside that item becomes its child list.

Frontend → HTML + CSS
Useful for categories, menus, course roadmaps and multi-level navigation.
→
roadmap.html

Web Development

  • Frontend
    • HTML
    • CSS
  • Backend
  • Database
Hierarchy: Frontend → HTML / CSS
Simple meaning: A Nested List is a list inside another list item. It creates a clear parent → child hierarchy, making multi-level information easier to organise and read.
