What is an HTML Table?

<table>
  <tr>
    <td>HTML</td>
    <td>Beginner</td>
  </tr>
</table>

<table>

Creates the table container.

<tr>

Creates one Table Row.

<td>

Creates a Table Data cell.

Simple meaning: An HTML table displays structured information using rows and columns. The basic building blocks are <table>, <tr> and <td>.
02 · Rows & Columns

Rows & Columns

<table>
  <tr>
    <td>Name</td>
    <td>Course</td>
  </tr>

  <tr>
    <td>Aman</td>
    <td>HTML</td>
  </tr>
</table>

<tr> = Table Row

Every <tr> starts a new horizontal row.

<td> = Table Data

Every <td> creates a cell inside that row.

Same position across rows forms a column.

→
students.html
NameCourse
AmanHTML
2 rows × 2 columns
Remember: A row is horizontal, while a column is vertical. Multiple rows can use the same column structure to keep related information aligned.
03 · Table Head & Body

Table Head & Table Body

<table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Marks</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Aman</td>
      <td>92</td>
    </tr>
  </tbody>
</table>

<thead>

Groups the table's heading rows.

<th> = Table Header

Labels what a column contains.

<tbody>

Groups the main data rows.

→
marks.html
NameMarks
Aman92
Simple meaning: <thead> organizes the heading section and <tbody> organizes the main data. Use <th> for cells that describe the columns.
04 · Colspan & Rowspan

Merge Table Cells

<table>
  <tr>
    <th colspan="2">Student</th>
  </tr>

  <tr>
    <td rowspan="2">Aman</td>
    <td>HTML</td>
  </tr>

  <tr>
    <td>CSS</td>
  </tr>
</table>

colspan

Makes one cell cover multiple columns.

colspan="2"

rowspan

Makes one cell cover multiple rows.

rowspan="2"
→
span-demo.html
Student
AmanHTML
CSS
Remember: colspan merges a cell across columns. rowspan merges a cell across rows. The number tells the browser how many columns or rows the cell should occupy.
05 · Practical Table

Build a Simple Product Table

<table>
  <thead>
    <tr>
      <th>Product</th>
      <th>Price</th>
      <th>Stock</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Keyboard</td>
      <td>₹799</td>
      <td>12</td>
    </tr>
    <tr>
      <td>Mouse</td>
      <td>₹499</td>
      <td>25</td>
    </tr>
  </tbody>
</table>

Real-world use

Tables are useful for product lists, marksheets, invoices, reports and dashboards.

Structure

table → thead / tbody → tr → th / td
