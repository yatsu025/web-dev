01 · Headings

Headings create the visual hierarchy of a webpage

<h1>My Website</h1>
<h2>About Me</h2>
<h3>My Skills</h3>

Heading Tags

<h1> → Main heading
<h2> → Subheading
<h3> → Smaller heading

HTML provides headings from h1 to h6. Usually, h1 is the main heading and the others create lower levels.

→
mywebsite.html
My Website

About Me

My Skills

Simple meaning: A heading tells the browser that a piece of text is a title or section heading. <h1> is the highest-level heading, while <h6> is the smallest heading level.
02 · Paragraphs

Use paragraphs for normal blocks of text

<p>HTML gives structure to a webpage.</p>
<p>We can write readable content using paragraphs.</p>

<p> Paragraph

A paragraph groups related sentences into a readable block of text.

The browser normally places separate paragraph elements on separate blocks.

→
student.html
My First Page

HTML gives structure to a webpage.

We can write readable content using paragraphs.

Simple meaning: <p> means paragraph. Use it when you have normal sentences, descriptions, introductions, or other text content that should appear as a paragraph.
03 · Line Break

Put the next text on a new line

<p>Hello!<br>Welcome to HTML.</p>

<br> Line Break

The <br> tag moves the following content to the next line.

It is useful when two pieces of text should stay in the same paragraph but appear on different lines.

→
page.html
Greeting

Hello!
Welcome to HTML.

Remember: <br> creates a line break, not a new paragraph. Think of it as pressing Enter to start the next line while staying in the same paragraph.
04 · Horizontal Rule

Use a line to separate sections

<h2>About Me</h2>
<p>I am a student.</p>
<hr>
<h2>My Skills</h2>

<hr> Horizontal Rule

It creates a visible thematic break between two parts of a webpage.

It is often used when one section of content ends and another section begins.

→
profile.html

About Me

I am a student learning web development.

My Skills

HTML · CSS · JavaScript

Simple meaning: <hr> means horizontal rule. It represents a thematic break — a visual separator between different topics or sections.
05 · Text Styles

Make important or emphasized text stand out

<strong>Important</strong>
<em>Emphasis</em>
<mark>Highlighted</mark>
<strong> → Important
<em> → Emphasis
<mark> → Highlighted
→
notice.html
Important: Submit your assignment.
Please read the instructions.
Exam on Monday
Meaning: strong gives strong importance, em means emphasis, and mark highlights text. These elements communicate meaning instead of simply making text look different.
06 · Quotes

Display quoted text clearly

<blockquote>
Learning never stops.
</blockquote>

<blockquote>

Used for a longer quotation or a statement taken from another source.

The browser can present the quotation as a separate block of content.

→
quote.html
“
Learning never stops.
— A simple quotation
Simple meaning: <blockquote> tells HTML that the enclosed text is a quotation. It is useful for displaying a longer quoted statement separately from normal page content.
