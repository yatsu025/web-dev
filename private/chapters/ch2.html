03 — MARKUP

HTML = Markup Language

Markup uses special notation to describe what content is — instead of only storing the content itself.

<h1>Welcome to HTML</h1>
<p>This is my first webpage.</p>
<a>Explore more</a>
Markup tells the browser the role
Content is what the user sees
Together → meaningful page structure
HTML describes content; it does not behave like a programming language.→ Next
05 / 08
04 — HTML5

HTML5

The modern evolution of HTML brought richer structure and built-in capabilities for today’s web.

Semantic structure

Elements such as header, nav, main, section and footer make page structure clearer.

Media

Audio and video can be embedded directly into webpages using HTML elements.

Better forms

Modern input types help browsers understand and validate common form data.

Meaningful markup

Clear structure can improve accessibility and how tools interpret a page.

Modern web

HTML works as the structural foundation across desktops, tablets and phones.

Still HTML

HTML5 is markup — not a programming language. CSS styles it; JavaScript adds behavior.

HTML5 = modern HTML standard & capabilities→ Next

07 — PAGE ANATOMY

Basic HTML Structure

A simple HTML document has an outer html element, with information in head and visible content in body.

<html> Entire document
<head> Page information
<title> My Website
<meta> Page metadata
<body> Visible page content
<h1> Welcome
<p> Hello World
Remember: Head stores page information. Body contains what visitors mainly see.
