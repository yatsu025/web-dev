HTML Tags & Their Meaning

A complete beginner-friendly reference of modern HTML elements, grouped by their purpose.

HTML = HyperText Markup Language

How to Read This Page

Tag: The HTML element name.

Meaning: What the element represents or does.

Example: A simple way to use the element.

Void element: An element that does not use a closing tag, such as <img> or <br>.

1. Document & Root

Tag Meaning / Purpose Example
<html> Root element of the complete HTML document. <html lang="en">
<head> Contains page metadata and resources that are not the main visible page content. <head>...</head>
<body> Contains the visible content of the web page. <body>Hello</body>
<!DOCTYPE html> Document type declaration that tells the browser to use modern HTML parsing. <!DOCTYPE html>

2. Document Metadata

Tag Meaning / Purpose Example
<title> Sets the title shown in the browser tab. <title>My Website</title>
<meta> Provides metadata such as character encoding, viewport and description. <meta charset="UTF-8">
<link> Connects the document with an external resource such as a stylesheet or icon. <link rel="stylesheet" href="style.css">
<style> Contains CSS rules inside the HTML document. <style>...</style>
<base> Sets the base URL used for relative URLs in a document. <base href="https://example.com/">

3. Semantic & Page Structure

Semantic elements describe the meaning or role of content, instead of being only generic containers.

Tag Meaning / Purpose Example
<header> Introductory content for a page or section, often containing a logo, heading or navigation. <header>...</header>
<nav> Contains important navigation links. <nav><a href="/">Home</a></nav>
<main> Contains the dominant main content of the document. <main>...</main>
<section> Groups related content into a meaningful section. <section>About</section>
<article> Represents self-contained content that can make sense independently. <article>Blog Post</article>
<aside> Contains content indirectly related to the main content, such as a sidebar or related information. <aside>Related Links</aside>
<footer> Footer for a page or section. <footer>Copyright</footer>
<address> Provides contact information for a page or article. <address>Email: hello@example.com</address>
<search> Represents a section containing controls related to searching or filtering. <search>...</search>
<hgroup> Groups a heading with related secondary content such as a subtitle or tagline. <hgroup>...</hgroup>

4. Headings

Tag Meaning Example
<h1> Highest-level heading. <h1>Website Title</h1>
<h2> Second-level heading. <h2>About</h2>
<h3> Third-level heading. <h3>Skills</h3>
<h4> Fourth-level heading. <h4>HTML</h4>
<h5> Fifth-level heading. <h5>Details</h5>
<h6> Sixth-level heading. <h6>Note</h6>

5. Text & Content

Tag Meaning / Purpose Example
<p> Paragraph of text. <p>Hello World</p>
<br> Creates a line break. Void element. Hello<br>World
<hr> Represents a thematic break between topics or sections. Void element. <hr>
<div> Generic block container with no special semantic meaning. <div>Content</div>
<span> Generic inline container with no special semantic meaning. <span>Text</span>
<pre> Displays preformatted text while preserving whitespace. <pre> Hello</pre>
<blockquote> Represents an extended quotation. <blockquote>A quote</blockquote>
<q> Represents a short inline quotation. <q>Hello</q>
<cite> Identifies the title of a creative work or a citation. <cite>Book Title</cite>
<abbr> Represents an abbreviation or acronym. <abbr title="HyperText Markup Language">HTML</abbr>
<code> Represents a short piece of computer code. <code>console.log()</code>
<kbd> Represents user keyboard input. <kbd>Ctrl</kbd> + <kbd>C</kbd>
<samp> Represents sample output from a computer program. <samp>File saved</samp>
<var> Represents a variable in a mathematical or programming expression. <var>x</var>

6. Inline Text Semantics

Tag Meaning / Purpose Example
<strong> Marks text as having strong importance. <strong>Important</strong>
<em> Marks text with emphasis. <em>Very important</em>
<b> Draws attention to text without adding strong importance. <b>Keyword</b>
<i> Represents text in an alternate voice or mood, such as a technical term. <i>HTML</i>
<u> Represents text with an annotation or non-textual indication. <u>Word</u>
<s> Represents content that is no longer accurate or relevant. <s>₹999</s>
<mark> Highlights text because it is relevant to the current context. <mark>Important</mark>
<small> Represents side comments or small print. <small>Terms apply</small>
<sub> Displays subscript text. H<sub>2</sub>O
<sup> Displays superscript text. x<sup>2</sup>
<time> Represents a date or time. <time>10:00</time>
<data> Associates visible content with a machine-readable value. <data value="101">Product</data>
<dfn> Marks the defining instance of a term. <dfn>HTML</dfn>
<bdi> Isolates text direction from surrounding text. <bdi>User123</bdi>
<bdo> Overrides the text direction. <bdo dir="rtl">Hello</bdo>
<ruby> Represents ruby annotation text used with East Asian typography. <ruby>漢<rt>kan</rt></ruby>
<rt> Provides the ruby annotation text. <rt>kan</rt>
<rp> Provides fallback parentheses for ruby annotations. <rp>(</rp>
<wbr> Suggests a possible line-break position. verylongword<wbr>example

7. Links & Navigation

Tag Meaning / Purpose Example
<a> Creates a hyperlink to another page, file, location or resource. <a href="about.html">About</a>
<map> Defines an image map containing clickable areas. <map name="campus">...</map>
<area> Defines a clickable area inside an image map. Void element. <area href="lab.html" shape="rect">

8. Images & Figures

Tag Meaning / Purpose Example
<img> Embeds an image. Void element. <img src="photo.jpg" alt="Photo">
<figure> Groups self-contained content such as an image, diagram or code example. <figure>...</figure>
<figcaption> Provides a caption for a figure. <figcaption>Campus Photo</figcaption>
<picture> Provides alternative image sources for different conditions or devices. <picture>...</picture>

9. Audio, Video & Media

Tag Meaning / Purpose Example
<audio> Embeds audio content. <audio controls>...</audio>
<video> Embeds video content. <video controls>...</video>
<source> Provides an alternative media source for audio, video or picture. <source src="video.mp4">
<track> Provides timed text such as subtitles or captions for media. <track kind="subtitles" src="en.vtt">

10. Embedded Content

Tag Meaning / Purpose Example
<iframe> Embeds another HTML document inside the current page. <iframe src="page.html"></iframe>
<embed> Embeds external content. <embed src="file.pdf">
<object> Represents an external resource. <object data="file.pdf"></object>
<canvas> Provides a drawing surface that can be controlled with scripts. <canvas></canvas>

11. Lists

Tag Meaning / Purpose Example
<ul> Unordered list, normally shown with bullets. <ul><li>HTML</li></ul>
<ol> Ordered list, normally shown with numbers or letters. <ol><li>Step 1</li></ol>
<li> Represents an item inside a list. <li>HTML</li>
<dl> Description list containing terms and descriptions. <dl>...</dl>
<dt> Term inside a description list. <dt>HTML</dt>
<dd> Description or value for a term in a description list. <dd>Markup language</dd>
<menu> Represents an unordered list of items, semantically similar to <ul>. <menu><li>Save</li></menu>

12. Tables

Tag Meaning / Purpose Example
<table> Creates a table. <table>...</table>
<caption> Provides a title or caption for a table. <caption>Students</caption>
<thead> Groups the header rows of a table. <thead>...</thead>
<tbody> Groups the main data rows of a table. <tbody>...</tbody>
<tfoot> Groups footer rows of a table. <tfoot>...</tfoot>
<tr> Creates a table row. <tr>...</tr>
<th> Creates a header cell. <th>Name</th>
<td> Creates a normal data cell. <td>Yash</td>
<colgroup> Groups one or more table columns. <colgroup>...</colgroup>
<col> Defines properties for one or more columns. Void element. <col span="2">

Common table attributes include colspan for spanning columns and rowspan for spanning rows.

13. Forms & User Input

Tag Meaning / Purpose Example
<form> Groups controls used to collect and submit user data. <form>...</form>
<input> Creates many types of single-line and interactive form controls. <input type="text">
<label> Provides a caption for a form control. <label for="email">Email</label>
<textarea> Creates a multi-line text input. <textarea>...</textarea>
<button> Creates a clickable button. <button>Submit</button>
<select> Creates a menu of options. <select>...</select>
<option> Represents one selectable option. <option>India</option>
<optgroup> Groups related options inside a select menu. <optgroup label="Asia">...</optgroup>
<datalist> Provides suggested options for an input. <datalist id="cities">...</datalist>
<fieldset> Groups related form controls. <fieldset>...</fieldset>
<legend> Provides a caption for a fieldset. <legend>Personal Details</legend>
<output> Represents the result of a calculation or user action. <output>100</output>
<progress> Displays progress toward completion of a task. <progress value="70" max="100">
<meter> Represents a scalar measurement within a known range. <meter value="7" min="0" max="10">
<selectedcontent> Displays the currently selected option's content inside a closed select control where supported. <selectedcontent></selectedcontent>

15. Interactive Elements

Tag Meaning / Purpose Example
<details> Creates a disclosure widget that can be opened and closed. <details>...</details>
<summary> Provides the visible heading for a details disclosure. <summary>More Info</summary>
<dialog> Represents a dialog box or other interactive modal-like component. <dialog open>Hello</dialog>

16. Document Changes

Tag Meaning / Purpose Example
<ins> Represents text that has been added to a document. <ins>New text</ins>
<del> Represents text that has been deleted from a document. <del>Old text</del>

17. Web Components

Tag Meaning / Purpose Example
<template> Stores HTML that is not rendered immediately and can be instantiated later. <template>...</template>
<slot> Defines a placeholder for content inside a Web Component. <slot></slot>

18. Scripting

Tag Meaning / Purpose Example
<script> Embeds or references executable code, commonly JavaScript. <script>...</script>
<noscript> Provides HTML content for situations where scripting is unavailable or disabled. <noscript>Enable JavaScript</noscript>

19. SVG & MathML Entry Elements

SVG and MathML are separate markup languages that can be embedded in HTML. Their elements are not ordinary HTML elements, but you will commonly encounter their root elements inside HTML documents.

Element Meaning
<svg> Root element for inline Scalable Vector Graphics.
<math> Root element for MathML mathematical markup.

20. Obsolete / Deprecated HTML Tags

These tags are listed for recognition and legacy code only. They should generally not be used in new projects. Modern HTML uses CSS and semantic elements instead.

Old Tag Old Purpose Modern Approach
<center> Centered content. Use CSS text-align or layout properties.
<font> Changed font appearance. Use CSS.
<big> Displayed larger text. Use CSS.
<strike> Displayed struck-through text. Use <s> or CSS depending on meaning.
<tt> Displayed teletype-style text. Use <code>, <kbd> or CSS according to meaning.
<acronym> Marked an acronym. Use <abbr>.
<dir> Old directory list. Use <ul>.
<frame> Created a frame inside a frameset. Use modern page structure or <iframe> when embedding is actually required.
<frameset> Defined a collection of frames. Use modern HTML layout and CSS.
<noframes> Fallback content for old frame-based pages. Use modern HTML structure.
<marquee> Created scrolling text or content. Use CSS animations or JavaScript when appropriate.
<acronym> Marked an acronym in older HTML. Use <abbr>.

Important Note

HTML has many elements, but you do not need to memorize every tag at once. Learn the common elements first and use a reference like this when you need a less-common element.

Also remember: HTML gives meaning and structure, CSS controls presentation, and JavaScript controls behavior.
