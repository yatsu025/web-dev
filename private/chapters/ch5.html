01 · Links

Make one webpage connect to another

<a href="about.html">About Us</a>

<a> Anchor Tag

href tells the browser where the link should go.

The text between the tags becomes clickable.

→
index.html
My Website

About Us

Clicking the link opens the destination.

Simple meaning: A link connects the current webpage to another page, website, file, or location. <a> is called the anchor element, and href means hypertext reference — the destination of the link.
02 · Absolute vs Relative Links

Two common ways to write a link destination

<a href="https://example.com">Website</a>

<a href="about.html">About</a>

Absolute URL

Complete web address including the protocol and domain.

https://example.com

Relative URL

A path relative to the current website/page.

about.html
→
mywebsite.com
Navigation

External Website
About Page

External destination ↗   |   Same website →
Remember: An absolute URL contains the complete address of a resource. A relative URL describes where the resource is in relation to the current page or website.
03 · Images

Show a picture inside your webpage

<img src="photo.jpg" alt="My Photo">

<img> Image Element

src tells the browser which image file to load.

alt provides alternative text describing the image.

→
gallery.html
My Gallery
PHOTO
Simple meaning: The <img> element displays an image. It is an empty element, so it does not use a normal closing tag. The src attribute points to the image file.
04 · Image Attributes

Tell the browser more about an image

<img
  src="photo.jpg"
  alt="College Campus"
  width="400"
  height="250"
>

Important Attributes

src → image location
alt → alternative text
width → image width
height → image height
→
campus.html
College Campus
400 × 250
Simple meaning: Attributes provide extra information about an image. alt is especially useful because it describes the image when it cannot be displayed and helps users using assistive technologies.
05 · Linking Images

An image can also work as a link

<a href="gallery.html">
  <img src="photo.jpg" alt="Gallery">
</a>

How it works

The image is placed inside the anchor element.

<a> → <img>

Clicking the image follows the link.

→
home.html
Our Gallery
CLICK IMAGE
This image is clickable
Simple meaning: HTML elements can be placed inside other elements. Here, the <img> is inside <a>, so the image becomes clickable and takes the user to the link destination.
06 · Paths

Tell HTML where your file is located

<img src="images/logo.png">

<a href="pages/about.html">About</a>

Folder Structure

website/
images/ → logo.png
pages/ → about.html

The path describes how to reach the file from the current location.

→
website/index.html
My Website
logo.png

About

Simple meaning: A path tells HTML where a file is located. For example, images/logo.png means “open the images folder and find logo.png.” Correct paths are essential for links and images to work.
